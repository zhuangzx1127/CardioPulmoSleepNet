# oxinet

Use `--hours 10 --seed 42` for the ten-hour reproduction. Run `evaluate` for cohort NPZ/metrics, and `export_test.py --run RUN --root REPOSITORY_ROOT` for unified JSON without training. The export script uses the run source snapshot, saved scaler, config and best weights.
